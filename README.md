# hamza-benfaddoul.me

Personal portfolio of Hamza Benfaddoul — one static page in HTML, CSS and vanilla JavaScript,
served by GitHub Pages from the `main` branch.

Preview it locally from this folder:

```bash
python3 -m http.server 5500
```

Then open http://localhost:5500. Notes on how the page is built and how to check a change
are in [CLAUDE.md](CLAUDE.md).
